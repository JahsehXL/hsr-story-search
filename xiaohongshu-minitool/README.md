# 星轨档案 · 小红书小工具工作区

本目录构建面向小红书创作服务平台小工具容器的离线静态检索包。

> [!IMPORTANT]
> **仅限离线检索与阅读体验**：本工作区**不展示网页版的站点公告按钮与首页公告弹窗**（相关逻辑仅位于网页版 [`frontend/src/App.tsx`](../frontend/src/App.tsx) 与 [`frontend/src/announcement.ts`](../frontend/src/announcement.ts)，切勿引入本目录）。

构建、打包与端到端验证命令见：[小红书小工具文档](../docs/xiaohongshu-minitool.md)。
